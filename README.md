## 🎯 О проекте

**Brute Force Password Tool** — учебный инструмент для:
- Восстановления паролей по известному хешу
- Проверки устойчивости паролей к словарным атакам
- Аудита Wi-Fi сетей (WPA/WPA2) через PMKID и EAPOL-рукопожатия

Работает **полностью на чистом Python** — без hashcat, aircrack-ng и других внешних крэкеров. Единственные зависимости — `colorama`, `scapy`, `pycryptodome`, `psutil`.

> ⚠️ **Только для образовательных целей и тестирования собственных сетей.** Использование против чужих систем без письменного разрешения незаконно.

## 🎮 Режимы работы

### 1. Обычные хеши

```
Меню → 2. Поиск по хешу
→ Выберите алгоритм (1-11)
→ Введите хеш
→ Перебор по pass.txt
```

Пример:
```
Выберите номер: 8
Введите SHA-256 хеш: 5ebe2294ecd0e0f08eab7690d2a6ee69...
```

### 2. Точный пароль

```
Меню → 3. Поиск по точному паролю
→ Введите пароль
→ Проверка наличия в pass.txt
```

### 3. Генерация хешей

```
Меню → 4. Создать хеши из пароля
→ Введите пароль
→ Получите хеши всех 18 алгоритмов
→ Опционально: сохранить в hashes.txt
```

### 4. Wi-Fi (PMKID / EAPOL)

```
Меню → 9. Поиск по Wi-Fi
→ Введите путь: hash.hc22000  (или capture.pcap / capture.pcapng)
```

**Что происходит:**
1. Парсинг целей (PMKID / EAPOL) из файла
2. Для `.pcap`/`.pcapng` — двухпроходный анализ:
   - Проход 1: карта `BSSID → SSID` из Beacon/Probe Response
   - Проход 2: извлечение PMKID и EAPOL Message 1/2
3. Многопоточный перебор по `pass.txt`
4. Вывод результата

**Пример вывода:**
```
[INFO] Парсинг raw pcap: capture.pcapng
[INFO] Цель [PMKID]: SSID='MyNetwork'
[INFO] Цель [EAPOL]: SSID='MyNetwork'
[INFO] Словарь: 10,000 паролей
[INFO] Потоков: 8
[ПРЕДУПРЕЖДЕНИЕ] PBKDF2 4096 итераций — CPU-bound

Проверено: 10,000/10,000 | 1234 п/с
[+] ПАРОЛЬ НАЙДЕН: correcthorsebatterystaple
    SSID: MyNetwork
```

## 📡 Wi-Fi: технические детали

### WPA/WPA2 PSK

```
PMK = PBKDF2-HMAC-SHA1(password, SSID, 4096, 32)
```

### PMKID (WPA*01)

```
PMKID = HMAC-SHA1(PMK, "PMK Name" + MAC_AP + MAC_STA)[:16]
```

Не требует рукопожатия — достаточно одного кадра Message 1.

### EAPOL (WPA*02)

```
PTK = PRF-512(PMK, "Pairwise key expansion",
              min(MACs) + max(MACs) + min(Nonces) + max(Nonces))
KCK = PTK[:16]
MIC = HMAC-SHA1(KCK, EAPOL_frame_with_zeroed_MIC)[:16]
```

Требует **пару** Message 1 (ANonce) + Message 2 (SNonce + MIC).

### Формат hc22000

```
WPA*01*PMKID*MAC_AP*MAC_STA*ESSID***
WPA*02*MIC*MAC_AP*MAC_STA*ESSID*NONCE*EAPOL*MP
```

### Генерация hc22000 из pcap

```bash
# Требуется hcxtools
hcxpcapngtool -o hash.hc22000 capture.pcapng
```

Либо используйте **встроенный парсер** — просто передайте `.pcap`/`.pcapng`.

## ⚠️ Ограничения

1. **Скорость Wi-Fi на CPU** — PBKDF2 с 4096 итерациями даёт ~500–2000 попыток/сек на ядро. Для больших словарей используйте GPU-инструменты.
2. **EAPOL требует полную пару** Message 1 + Message 2. Если в дампе только один кадр — цель не будет создана.
3. **SSID должен быть в дампе** (Beacon или Probe Response). Если SSID скрыт — парсер не сможет сопоставить.
4. **WPA3 (SAE)** не поддерживается — там другой протокол (Hash-to-Element).
5. **`scapy` парсит потоково**, но для очень больших pcap (>1 ГБ) может быть медленно.
